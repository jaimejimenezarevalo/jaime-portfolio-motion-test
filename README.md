# Jaime Portfolio Motion Test

This repository is a test version of Jaime Jimenez Arevalo's academic portfolio. The opening title page transforms into the compact navigation header as the visitor scrolls.

## Publish with GitHub Pages

1. Upload every item in this folder to the top level of the repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Choose **main** and **/ (root)**.
5. Click **Save**.

The test site should appear at:

`https://jaimejimenezarevalo.github.io/jaime-portfolio-motion-test/`

## File structure

```text
index.html
styles.css
script.js
assets/
  headshot.jpg
  Jaime-Jimenez-Arevalo-CV.pdf
```

## Notes

- Desktop browsers receive the full scroll-linked transformation.
- Mobile devices use a compact header and menu so the animation does not become crowded.
- Visitors who prefer reduced motion receive a simplified transition.
